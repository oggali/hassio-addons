# 🏷️ Herrhors login Home Assistant Add-on

This add-on runs [Herrhors electricity consumption login](https://identity.herrfors.fi/?locale=fi-FI) inside Home Assistant Supervised or OS installations.
It fetches token which can be used to query consumption metrics
